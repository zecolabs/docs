</Warning>

## Source code

All implementation code is available in our [GitHub repository](https://github.com/zecolabs/wallet).

## Conventions

- All RPC examples use Python with the `requests` library.
- The examples assume a node running at `http://127.0.0.1:3000`.
- Large integers are returned as decimal strings. See the [RPC overview](/rpc/overview).
