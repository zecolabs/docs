---
title: "Get block"
description: "Get the details of a block by its number."
---

`GET /block/:number`

```python
r = requests.get(rpc_url + "/block/1")
block = r.json()

STATUS = ["processed", "confirmed", "finalized"]
status = STATUS[block["status"]] if block.get("status") is not None else "not found"
print(status)
```

## Status values

| Value | Meaning |
| --- | --- |
| `0` | processed |
| `1` | confirmed |
| `2` | finalized |

## Fields

| Field | Type | Description |
| --- | --- | --- |
| `status` | uint8 | See status values above |
| `version` | uint8 | Block format version |
| `chainid` | uint32 | Chain identifier |
| `blocknumber` | uint64 | Block number |
| `blockhash` | string | Block hash |
| `timestamp` | uint64 | Block timestamp |
| `worker` | object | `address` and `public_key` of the worker that produced the block |
| `previous_blockhash` | string | Hash of the previous block |
| `state_root` | string | State root after this block |
| `transaction_root` | string | Root of the block's transactions |
| `power_used` | uint64 | Total power used in the block |
| `power_limit` | uint64 | Power limit of the block |
| `fees_collected` | uint256 | Total fees collected |
| `tips_collected` | uint256 | Total tips collected |
| `transaction_count` | uint16 | Number of transactions |
| `transaction` | array | Hashes of the transactions in the block |
| `signature` | string | Block signature |

## Errors

```json
{
  "error": "block not found"
}
```
