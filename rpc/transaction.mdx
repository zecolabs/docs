---
title: "Get transaction"
description: "Get the details of a transaction by its hash."
---

`GET /transaction/:tx_hash`

The hash is `rx` followed by 64 hex characters.

```python
r = requests.get(rpc_url + "/transaction/rx5cfae028bc91b7b69e7797cad2f2e13881a254efdad600009bf3be3d8f9a9893")
tx = r.json()

STATUS = ["pending", "success", "failed"]
status = STATUS[tx["status"]] if tx.get("status") is not None else "not found"
print(status)
```

## Status values

| Value | Meaning |
| --- | --- |
| `0` | pending |
| `1` | success |
| `2` | failed |

## Fields

| Field | Type | Description |
| --- | --- | --- |
| `hash` | string | Transaction hash |
| `version` | uint8 | Transaction format version |
| `status` | uint8 | See status values above |
| `blocknumber` | uint64 | Block that contains the transaction |
| `position` | uint16 | Position of the transaction inside the block |
| `timestamp` | uint64 | Block timestamp |
| `power_used` | uint64 | Power actually used |
| `fee` | uint256 | Fee charged |
| `event` | string | Transfer actions have no event, so this is `00` on hex. Other actions may return bytes hex |
| `chainid` | uint32 | Chain identifier |
| `action` | uint8 | The action performed |
| `sender` | object | Sender `address` and `public_key` |
| `to` | string | Recipient address |
| `nonce` | uint64 | Sender nonce |
| `amount` | uint256 | Amount sent |
| `power` | uint64 | Power for the transaction |
| `power_limit` | uint64 | Maximum power allowed by the sender |
| `price_per_power` | uint256 | Price per unit of power |
| `packet` | string | A plain transfer has no packet, so this is `00` on hex. Other actions may return bytes hex |
| `tip` | uint256 | Tip |
| `signature` | string | Transaction signature |

## Errors

```json
{
  "error": "transaction not found"
}
```
