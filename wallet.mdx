## Ready-made wallet

We provide open-source wallet. They are available as:

- a Chrome extension
- a terminal wallet in Python with ui

We provide a tutorial on how to install a ready-made wallet and also a tutorial on how to build one yourself. It's all here [zecolabs/wallet](https://github.com/zecolabs/wallet)

## Build your own

You can also build your own wallet by following the implementation we provide. See [Transactions](/concepts/transactions) for how to build and sign a transaction, and the [RPC API](/rpc/overview) for how to send it.

<Warning>
  Never share your private key with anyone.
</Warning>
